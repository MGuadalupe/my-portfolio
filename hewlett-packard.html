Smart Digitization: AI that turns drawings into vector files

Smart Digitization is HP’s solution to vectorize architectural drawings using only artificial intelligence. I worked on the interface, the research and the pilots that tested whether people would pay for it.

RoleInteraction designer
TeamLarge Format · HP Barcelona
ScopeInterface refactor, A/B tests, usability testing
UsersArchitects, resellers, interior designers
01 · Overview

From outsourcing to automation

Vectorizing a drawing means redrawing it by hand. HP wanted a generative AI engine to do it in minutes.

Today

Outsourcing

$300per drawing, at most
3 daysper drawing, at most

Vectorization is outsourced to companies that charge $60 to $300 per drawing.

It’s a manual job: redoing the drawing can take up to 3 days of work.

When users try to solve it with an existing tool, the quality of the result is very poor.

Tomorrow

Automated conversions

$30per drawing, at most
Minutesper drawing

A generative AI engine recognizes each entity of the plan and converts it. Three steps:

01Upload the file
02The AI converts the raster file into a vector file
03The user downloads the file
Business outcome

Validate the willingness to pay from customers.

Increase the amount of data to improve ML accuracy in conversions.

04 · Impact

What the numbers told us

Drop-out reduced Asking users for metadata, like what type of plan it is, reduced conversion time and prevented drop-out.
Output satisfaction Asking for feedback on conversions showed us how well trained the engine was after receiving a massive amount of plans, and how engaged users were.
Willingness to pay The preview of the converted file showed that only a small group, interior designers, was willing to pay, due to the lack of accuracy.
05 · Quantitative research

Pilots, A/B tests and feedback loops

A solution we created to run a pilot outside HP: understand that audience better, train the engine, and A/B test which interface improves the experience.

02 · Benchmark

We asked users to compare our competitors’ vectorization with HP’s.

HP’s main strength is line and node accuracy. HP’s main weakness is broken lines. HP doesn’t perform well enough on detailed design and entities. HP takes longer than other solutions to convert a plan.
One of the tests between HP and Scan2CAD
03 · Usability test

We ran a usability test with HP’s current prototype.

The main problem: users can’t follow the state of each conversion. Users didn’t understand what each state meant (Converting, Converted, Completed, Downloaded, Expired).
07 · Learnings

We need to train the engine.

01The scenarios are more complex than we thought.
02The interface isn’t clear to users.
03The plans users work with don’t match the inputs the engine expects.
04The conversion process is considerably slow.
05The accuracy of the output is very low.
